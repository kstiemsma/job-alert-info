Privacy policy

Last updated: October 13, 2026

This policy describes the personal MA-NH Job Alerts project maintained by GitHub user kstiemsma. It applies to the job scraper, its Gmail authorization and this information website.

Information used

  • Public job listings: employer names, job titles, locations, listing links, available posting dates and when the scraper first or last saw a listing.
  • Gmail authorization information: OAuth credentials and tokens used to authorize sending email from the owner's Google account.
  • The configured recipient email address and job alert emails generated by the scraper.

The app requests only the Gmail API gmail.send scope. It does not read, search or delete inbox messages, access Google contacts or calendars, or collect account passwords. OAuth sign-in and consent take place through Google.

Purpose and sharing

Authorization information is used only to send the requested job alert emails. Public listing history is used to identify newly discovered jobs and avoid repeat alerts. Google user data is not sold, used for advertising, or used to train AI models.

Google processes the authorization and email delivery. GitHub hosts this website and runs the scraper through GitHub Actions. The project owner stores the recipient address and Gmail token in GitHub Actions secrets so they can be provided to the running scraper. Job listings are sent to the configured recipient. The project does not intentionally share OAuth tokens or recipient information publicly.

Storage and retention

The local authorization helper creates a token file on the owner's computer. The workflow uses the token to send mail; the job history database is retained through GitHub's cache facilities. Job history is kept for deduplication until the owner deletes it or its cache expires. Local credentials and GitHub secrets remain until the owner removes or replaces them. Sent and received alert emails remain in the relevant Gmail accounts under Google's settings and retention controls.

This information website does not have a credential form or install application analytics or advertising trackers. GitHub and Google may retain operational records according to their own policies.

Control and deletion

The owner can stop alerts by disabling the scheduled trigger or workflow. Gmail authorization can be revoked through Google Account connections. To remove the project's stored authorization information, delete the Gmail token secret, any generated token files and local credential files. Job history can be removed by deleting the project's database and associated GitHub caches. Revoking access does not delete previously sent emails; those can be deleted in Gmail.

Contact and changes

Contact the maintainer through the project's GitHub issue page or GitHub profile. Do not include passwords, OAuth tokens or private credentials in a public issue. This policy will be updated when the project's data handling changes.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
