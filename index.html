Personal job alert project

MA-NH Job Alerts

MA-NH Job Alerts checks public employer career pages for jobs in Massachusetts and New Hampshire. It compares listings with saved job history and emails newly discovered opportunities to the project owner's configured address.

How it works

The Python scraper runs through GitHub Actions on a daily schedule. Alerts include the employer, job title, location and a link to the listing. Selected high-volume sources have engineering-related filters.

Gmail access

The project uses Google's Gmail API and the gmail.send permission to send job alert emails from the owner's authorized account. It does not request permission to read, search or delete inbox messages. Authorization is completed by the owner using a local helper; this website does not collect credentials or offer an account sign-in.

This is a personal project maintained by GitHub user kstiemsma, rather than a public email or recruiting service.
